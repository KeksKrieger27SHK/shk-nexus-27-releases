# SHK Nexus 27 – Downloads

SHK Nexus 27 ist eine kostenlose, nicht kommerzielle und vollständig offline nutzbare Informations-App für Stronghold Kingdoms. Nur die freiwillige Updateprüfung benötigt eine Internetverbindung.

## Richtigen Download wählen

| Betriebssystem | Download |
|---|---|
| Windows 64 Bit | `SHK-Nexus-27-Windows-x64-Setup.exe` |
| macOS mit M1/M2/M3/M4 oder neuer | `SHK-Nexus-27-macOS-Apple-Silicon.dmg` |
| macOS mit Intel-Prozessor | `SHK-Nexus-27-macOS-Intel.dmg` |

Version 0.23.0 muss einmal vollständig installiert werden. Danach kann die App passende `.shkupd`-Pakete selbst laden und geprüft installieren. Die lokale Funktion **Update-Datei** bleibt als Notfallweg erhalten.

Die Pakete sind zunächst nicht digital signiert. Unter Windows kann deshalb SmartScreen erscheinen; wähle **Weitere Informationen → Trotzdem ausführen**. Unter macOS kann nach dem ersten Startversuch unter **Systemeinstellungen → Datenschutz & Sicherheit** die Schaltfläche **Dennoch öffnen** verwendet werden. Vergleiche bei Bedarf die SHA-256-Prüfsumme mit `SHA256SUMS.txt`.

## English

SHK Nexus 27 is a free, non-commercial Stronghold Kingdoms information app that remains fully usable offline. Only the optional update check needs an internet connection.

| Operating system | Download |
|---|---|
| Windows 64-bit | `SHK-Nexus-27-Windows-x64-Setup.exe` |
| macOS with M1/M2/M3/M4 or newer | `SHK-Nexus-27-macOS-Apple-Silicon.dmg` |
| macOS with an Intel processor | `SHK-Nexus-27-macOS-Intel.dmg` |

The initial packages are unsigned. Windows SmartScreen users can select **More info → Run anyway**. On macOS, use **System Settings → Privacy & Security → Open Anyway** after the first blocked launch. `SHA256SUMS.txt` contains the verification hashes.
